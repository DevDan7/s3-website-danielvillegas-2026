01em produçãoindividual

AI Mentoring — plataforma de mentoria AWS com IA generativa

Plataforma serverless usada por turmas reais de mentoria para a certificação AWS Cloud Practitioner. Fotos de provas enviadas ao S3 passam por SQS + DLQ até uma Lambda que usa Claude no Amazon Bedrock para OCR e estruturação em JSON, alimentando um banco de questões no DynamoDB. Os alunos fazem diagnóstico, prática por tema e exame final de 65 questões via API Gateway com autenticação Cognito (JWT) e frontend no Amplify. Infraestrutura 100% Terraform com CI/CD no GitHub Actions via OIDC.

flowS3→SQS + DLQ→Lambda→Bedrock (Claude)→DynamoDB→API Gateway + Cognito→Amplify
#Bedrock#Terraform#Lambda#Cognito#DynamoDB#GitHubActions
